# Loan Approval Expert System

## Description
AI-based system for predicting loan approval using:
- Logistic Regression
- Decision Tree
- Naive Bayes
- Rule-based system

## Features
- Data preprocessing
- Model training & evaluation
- Performance metrics (Accuracy, Precision, Recall, F1)

## Tech Stack
- Python
- Scikit-learn
- Pandas

## Results
- Logistic Regression Accuracy: 82%
- Decision Tree Accuracy: 67%
